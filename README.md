## GitHub Pages

1. **Settings → Pages**로 이동합니다.
2. Source: **Deploy from a branch**
3. Branch: **main**, Folder: **/(root)**
4. **Save**

정적 HTML·CSS·JavaScript·JSON·이미지 파일로 구성되어 별도 빌드가 필요하지 않습니다. 시작 파일은 `index.html`입니다.
