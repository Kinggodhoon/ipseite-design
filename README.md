# ipséité 앱·웹 디자인 시안

선수 앱 27개 · 관리자 웹 26개 · 선수 웹 8개 · 공통 기준 2개, 총 **63개 화면**의 구성과 디자인 의도를 확인하는 정적 갤러리입니다.

밝은 파란색과 흰 바탕, Pretendard를 사용합니다. 역할별 필터·화면 검색·확대 보기·디자인 설명·이전/다음 이동·화면별 링크를 제공합니다. 측정 조건·기준 자세·개인 기록 비교·측정 계획·자가평가·착용 불편·회차 제출본 등의 시안을 포함합니다.

모든 기록과 측정값은 가상 예시입니다. 실제 서비스나 센서에 연결하지 않으며, 앱 기능의 동작을 시연하는 페이지는 아닙니다.

## GitHub Pages 설정

이 브랜치에는 게시할 정적 파일만 루트에 있습니다. 빌드 명령이나 npm 설치 없이 설정합니다.

1. 저장소 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 선택합니다.
3. Branch는 **main**, Folder는 **/(root)**로 선택합니다.
4. **Save**를 누릅니다.

이 커밋은 파일 준비와 업로드입니다. Pages 활성화 및 저장소 공개 범위는 변경하지 않습니다. 비공개 저장소에서 Pages를 이용할 수 있는지는 조직의 GitHub 요금제·정책에 따릅니다.

다른 정적 호스팅에서는 이 폴더를 게시 디렉토리로 지정하고, 빌드 명령을 비워 두면 됩니다. 시작 파일은 `index.html`입니다. 모든 자산 경로는 상대 경로여서 저장소 이름이 붙는 하위 경로도 지원합니다.

## 확인한 범위

- 390·768·1280px에서 필터·검색·결과 없음·확대·키보드 이동·닫기 확인
- 63개 이미지·디자인 설명·개별 링크 및 새로고침 확인
- 저장소 하위 경로에서 글꼴·이미지·JSON 확인
- 검수 중 JavaScript/HTTP 오류 및 외부/API 요청 없음

정적 파일의 검수 결과이며 실제 센서 정확도나 앱 기능 검증을 뜻하지 않습니다.
